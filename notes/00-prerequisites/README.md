# 前置知识笔记

主题范围：Python、C/C++、Linux、数学、Transformer、PyTorch、GPU 拓扑与集合通信。

建议从以下最小主题开始，而不是预先创建空文件：

1. Transformer shape 与参数量推导；
2. PyTorch 训练循环和 checkpoint；
3. GPU 存储层次与拓扑；
4. AllReduce、AllGather、ReduceScatter 数据流和通信量。

验收标准见 [../../roadmap/learning-path.md](../../roadmap/learning-path.md)。需要用代码建立概念映射时，将带注释示例放入 [../../examples/00-prerequisites/README.md](../../examples/00-prerequisites/README.md) 所在目录；代码默认仅供阅读，不要求运行。对应的真实面试题、回答骨架和递进追问放在 [../../interview/00-prerequisites/README.md](../../interview/00-prerequisites/README.md) 所在目录，主题须同时通过知识与面试验收。

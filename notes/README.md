# 知识笔记

知识笔记按学习阶段组织，每个主题使用一个小写英文连字符命名的 Markdown 文件。与主题配套的代码放入 `examples/<stage>/`，真实面试题、回答骨架和追问放入 `interview/<stage>/`；三者相互链接，但不重复堆放相同内容。

跨主题的已解决问题和较难知识点，统一索引在 [review-index.md](review-index.md)，方便长期复盘并回到原网站定位。

## 目录

- `00-prerequisites/`：编程、Linux、数学、Transformer、PyTorch、GPU 与集合通信。
- `01-cuda-operators/`：GPU 架构、CUDA Kernel、经典算子、Triton 与性能分析。
- `02-distributed-training/`：显存账本、并行策略、混合精度、MoE 与训练框架。
- `03-inference-serving/`：推理基础、KV Cache、推理引擎、量化、推测解码与服务 Benchmark。

## 推荐结构

不要机械补齐空章节；按主题需要选用：

```markdown
# 主题

## 学习目标
## 核心概念
## 原理与数据流
## 公式或维度推导
## 实现或教学代码导读
## 性能与资源分析
## Trade-off
## 常见误区
## 对应面试题
## 验收清单
## 参考资料
```

## 记录规则

- 张量注明 shape、dtype、device。
- 公式注明假设、单位和推导过程。
- 未实际运行的教学代码或性能设想必须明确标记，不写成实验结果。
- 明确区分“一级来源结论”“二手资料解释”“面经样本”和“个人推断”。
- 新主题应回答：解决什么问题、瓶颈在哪里、如何实现、牺牲什么、如何验证。
- 每个成熟主题链接对应的核心面试题，并记录容易遗漏的机制、定量或边界追问。
